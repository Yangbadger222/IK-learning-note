## 2.1 三角函数回顾

### 2.1.1 基本三角函数

在直角三角形中：

```math
\sin\theta = \frac{\text{对边}}{\text{斜边}} \quad \cos\theta = \frac{\text{邻边}}{\text{斜边}} \quad \tan\theta = \frac{\text{对边}}{\text{邻边}}
```

**单位圆定义**：
- 在单位圆上，点 $(x, y)$ 对应角度 $\theta$
- $x = \cos\theta$
- $y = \sin\theta$

**例题 2.1**：
```
在直角三角形中，斜边长度为10，角度为30°
求对边和邻边的长度
```

**解答**：

```math
\text{对边} = 10 \sin(30°) = 10 \times 0.5 = 5
```

```math
\text{邻边} = 10 \cos(30°) = 10 \times \frac{\sqrt{3}}{2} \approx 8.66
```

### 2.1.2 重要三角函数值

| 角度 | 0° | 30° | 45° | 60° | 90° |
|------|-----|-----|-----|-----|-----|
| 弧度 | 0 | π/6 | π/4 | π/3 | π/2 |
| sin | 0 | 1/2 | √2/2 | √3/2 | 1 |
| cos | 1 | √3/2 | √2/2 | 1/2 | 0 |
| tan | 0 | √3/3 | 1 | √3 | ∞ |

### 2.1.3 角度与弧度转换

```math
\text{弧度} = \text{角度} \times \frac{\pi}{180}
```

```math
\text{角度} = \text{弧度} \times \frac{180}{\pi}
```

**例题 2.2**：
```
将60°转换为弧度
```

**解答**：

```math
60° = 60 \times \frac{\pi}{180} = \frac{\pi}{3} \approx 1.047 \text{ 弧度}
```

### 2.1.4 重要三角恒等式

1. **毕达哥拉斯恒等式**：

```math
\sin^2\theta + \cos^2\theta = 1
```

2. **和角公式**：

```math
\sin(\alpha + \beta) = \sin\alpha \cos\beta + \cos\alpha \sin\beta
```

```math
\cos(\alpha + \beta) = \cos\alpha \cos\beta - \sin\alpha \sin\beta
```

3. **倍角公式**：

```math
\sin(2\theta) = 2\sin\theta\cos\theta
```

```math
\cos(2\theta) = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta
```

**例题 2.3**：
```
已知 sin(θ) = 0.6，且θ在第一象限
求 cos(θ) 和 tan(θ)
```

**解答**：
使用 $\sin^2\theta + \cos^2\theta = 1$：

```math
\cos^2\theta = 1 - 0.6^2 = 1 - 0.36 = 0.64
```

```math
\cos\theta = 0.8
```

 （第一象限为正）

```math
\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{0.6}{0.8} = 0.75
```

## 2.2 反三角函数

### 2.2.1 定义

- $\arcsin(x)$ 或 $\sin^{-1}(x)$：返回值域 $[-\frac{\pi}{2}, \frac{\pi}{2}]$
- $\arccos(x)$ 或 $\cos^{-1}(x)$：返回值域 $[0, \pi]$
- $\arctan(x)$ 或 $\tan^{-1}(x)$：返回值域 $(-\frac{\pi}{2}, \frac{\pi}{2})$

### 2.2.2 atan2函数（重要！）

在编程中，`atan2(y, x)` 函数更常用：
- 返回从原点到点(x, y)的角度
- 值域：$(-\pi, \pi]$
- 可以正确处理所有四个象限

**例题 2.4**：
```
求从原点到点(3, 3)的角度
```

**解答**：

```math
\theta = \arctan\left(\frac{3}{3}\right) = \arctan(1) = 45° = \frac{\pi}{4}
```

或使用atan2：

```math
\theta = \text{atan2}(3, 3) = 45°
```

**例题 2.5**：
```
求从原点到点(-1, 1)的角度
```

**解答**：
普通arctan会给出错误结果，应使用atan2：

```math
\theta = \text{atan2}(1, -1) = 135° = \frac{3\pi}{4}
```

## 2.3 2D笛卡尔坐标系

### 2.3.1 坐标系定义

- **原点**：O(0, 0)
- **x轴**：水平向右为正
- **y轴**：垂直向上为正
- **点表示**：P(x, y)

### 2.3.2 距离公式

两点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$ 之间的距离：

```math
d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}
```

**例题 2.6**：
```
求点A(1, 2)和点B(4, 6)之间的距离
```

**解答**：

```math
d = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} = 5
```

## 2.4 极坐标系

### 2.4.1 极坐标定义

点用 $(r, \theta)$ 表示：
- $r$：到原点的距离（半径）
- $\theta$：与x轴正方向的夹角

### 2.4.2 笛卡尔坐标与极坐标转换

**笛卡尔 → 极坐标**：

```math
r = \sqrt{x^2 + y^2}
```

```math
\theta = \text{atan2}(y, x)
```

**极坐标 → 笛卡尔**：

```math
x = r\cos\theta
```

```math
y = r\sin\theta
```

**例题 2.7**：
```
将笛卡尔坐标(3, 4)转换为极坐标
```

**解答**：

```math
r = \sqrt{3^2 + 4^2} = 5
```

```math
\theta = \text{atan2}(4, 3) = \arctan\left(\frac{4}{3}\right) \approx 53.13° \approx 0.927 \text{ 弧度}
```

极坐标：$(5, 53.13°)$

**例题 2.8**：
```
将极坐标(10, 60°)转换为笛卡尔坐标
```

**解答**：

```math
x = 10 \cos(60°) = 10 \times 0.5 = 5
```

```math
y = 10 \sin(60°) = 10 \times \frac{\sqrt{3}}{2} \approx 8.66
```

笛卡尔坐标：$(5, 8.66)$

## 2.5 3D笛卡尔坐标系

### 2.5.1 坐标系定义

三个互相垂直的轴：
- **x轴**
- **y轴**  
- **z轴**

**右手坐标系**（常用）：
- 右手拇指指向x轴正方向
- 食指指向y轴正方向
- 中指指向z轴正方向

点表示：$P(x, y, z)$

### 2.5.2 3D距离公式

```math
d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}
```

**例题 2.9**：
```
求点A(1, 2, 3)和点B(4, 6, 8)之间的距离
```

**解答**：

```math
d = \sqrt{(4-1)^2 + (6-2)^2 + (8-3)^2} = \sqrt{9 + 16 + 25} = \sqrt{50} \approx 7.07
```

## 2.6 3D球坐标系

### 2.6.1 球坐标定义

点用 $(r, \theta, \phi)$ 表示：
- $r$：到原点的距离
- $\theta$：方位角（在xy平面上的投影与x轴的夹角）
- $\phi$：仰角（与z轴的夹角）

### 2.6.2 转换公式

**笛卡尔 → 球坐标**：

```math
r = \sqrt{x^2 + y^2 + z^2}
```

```math
\theta = \text{atan2}(y, x)
```

```math
\phi = \arccos\left(\frac{z}{r}\right)
```

**球坐标 → 笛卡尔**：

```math
x = r\sin\phi\cos\theta
```

```math
y = r\sin\phi\sin\theta
```

```math
z = r\cos\phi
```

**例题 2.10**：
```
将笛卡尔坐标(0, 0, 5)转换为球坐标
```

**解答**：

```math
r = \sqrt{0^2 + 0^2 + 5^2} = 5
```

```math
\theta = \text{atan2}(0, 0) = 0
```

 （未定义，但通常取0）

```math
\phi = \arccos\left(\frac{5}{5}\right) = \arccos(1) = 0°
```

球坐标：$(5, 0°, 0°)$（在z轴正方向上）

## 2.7 坐标变换：平移

### 2.7.1 2D平移

将点 $P(x, y)$ 平移向量 $\vec{t} = (t_x, t_y)$：

```math
P' = P + \vec{t} = (x + t_x, y + t_y)
```

**例题 2.11**：
```
点P(2, 3)沿向量(1, -2)平移，求新坐标
```

**解答**：

```math
P' = (2+1, 3+(-2)) = (3, 1)
```

### 2.7.2 3D平移

```math
P'(x', y', z') = (x+t_x, y+t_y, z+t_z)
```

---

## 2.8 坐标变换：缩放

### 2.8.1 2D缩放

```math
x' = s_x \cdot x
```

```math
y' = s_y \cdot y
```

**例题 2.12**：
```
点P(2, 3)在x方向缩放2倍，y方向缩放3倍
```

**解答**：

```math
P' = (2 \times 2, 3 \times 3) = (4, 9)
```

## 2.9 坐标变换：旋转（2D）

### 2.9.1 绕原点旋转

点 $P(x, y)$ 绕原点逆时针旋转角度 $\theta$：

```math
x' = x\cos\theta - y\sin\theta
```

```math
y' = x\sin\theta + y\cos\theta
```

**例题 2.13**：
```
点P(1, 0)绕原点逆时针旋转90°
```

**解答**：

```math
x' = 1 \times \cos(90°) - 0 \times \sin(90°) = 0
```

```math
y' = 1 \times \sin(90°) + 0 \times \cos(90°) = 1
```

新坐标：$P'(0, 1)$

**例题 2.14**：
```
点P(2, 0)绕原点逆时针旋转45°
```

**解答**：

```math
x' = 2\cos(45°) - 0\sin(45°) = 2 \times \frac{\sqrt{2}}{2} = \sqrt{2} \approx 1.414
```

```math
y' = 2\sin(45°) + 0\cos(45°) = 2 \times \frac{\sqrt{2}}{2} = \sqrt{2} \approx 1.414
```

新坐标：$P'(\sqrt{2}, \sqrt{2})$

## 💡 关键要点总结

1. **角度与弧度**：$1° = \frac{\pi}{180}$ 弧度
2. **atan2函数**：比arctan更可靠，能处理所有象限
3. **极坐标转换**：
   - $r = \sqrt{x^2 + y^2}$
   - $\theta = \text{atan2}(y, x)$
4. **2D旋转公式**：
   - $x' = x\cos\theta - y\sin\theta$
   - $y' = x\sin\theta + y\cos\theta$
5. **右手坐标系**：IK中的标准
6. **毕达哥拉斯定理**在各处都有应用

## 8.1 问题描述

### 8.1.1 双关节机械臂

考虑一个2D平面上的双关节机械臂：
- 第一段长度：$L_1$
- 第二段长度：$L_2$
- 第一段角度：$\theta_1$（相对于x轴）
- 第二段角度：$\theta_2$（相对于第一段）

**正向运动学（已知角度，求位置）**：
$$x = L_1\cos\theta_1 + L_2\cos(\theta_1 + \theta_2)$$
$$y = L_1\sin\theta_1 + L_2\sin(\theta_1 + \theta_2)$$

**逆向运动学（已知位置，求角度）**：
给定目标位置 $(x, y)$，求 $\theta_1$ 和 $\theta_2$。

这就是**双关节IK问题**！

---

## 8.2 可达性分析

### 8.2.1 工作空间

机械臂末端可以到达的区域称为**工作空间**。

对于双关节机械臂：
- 最远距离：$d_{max} = L_1 + L_2$（完全伸展）
- 最近距离：$d_{min} = |L_1 - L_2|$（完全折叠）

**可达条件**：
$$|L_1 - L_2| \leq d \leq L_1 + L_2$$

其中 $d = \sqrt{x^2 + y^2}$ 是目标点到原点的距离。

**例题 8.1**：
```
机械臂参数：L₁ = 3, L₂ = 2
判断以下目标点是否可达：
(a) (4, 0)
(b) (6, 0)
(c) (0.5, 0)
```

**解答**：

工作空间：
- $d_{max} = 3 + 2 = 5$
- $d_{min} = |3 - 2| = 1$

(a) $d = 4$，因为 $1 \leq 4 \leq 5$，**可达** ✓

(b) $d = 6$，因为 $6 > 5$，**不可达** ✗

(c) $d = 0.5$，因为 $0.5 < 1$，**不可达** ✗

## 8.3 余弦定理解法

### 8.3.1 数学推导

使用**余弦定理**求解双关节IK。

设目标点距离原点：$d = \sqrt{x^2 + y^2}$

**步骤1：求 $\theta_2$**

根据余弦定理：
$$d^2 = L_1^2 + L_2^2 - 2L_1 L_2 \cos(\pi - \theta_2)$$

因为 $\cos(\pi - \theta_2) = -\cos\theta_2$：
$$d^2 = L_1^2 + L_2^2 + 2L_1 L_2 \cos\theta_2$$

解出：
$$\cos\theta_2 = \frac{d^2 - L_1^2 - L_2^2}{2L_1 L_2}$$

$$\theta_2 = \pm \arccos\left(\frac{d^2 - L_1^2 - L_2^2}{2L_1 L_2}\right)$$

**两个解**：
- $\theta_2 > 0$："肘部向上"（elbow-up）
- $\theta_2 < 0$："肘部向下"（elbow-down）

**步骤2：求 $\theta_1$**

设 $\alpha = \text{atan2}(y, x)$（目标点的方向角）

设 $\beta$ 为第一段与目标方向的夹角：
$$\beta = \arctan\left(\frac{L_2\sin\theta_2}{L_1 + L_2\cos\theta_2}\right)$$

或使用atan2更稳定：
$$\beta = \text{atan2}(L_2\sin\theta_2, L_1 + L_2\cos\theta_2)$$

则：
$$\theta_1 = \alpha - \beta$$

### 8.3.2 完整算法

```
输入：目标位置(x, y)，链长L₁, L₂
输出：关节角度θ₁, θ₂

1. 计算d = sqrt(x² + y²)
2. 检查可达性：|L₁ - L₂| ≤ d ≤ L₁ + L₂
3. 计算cos(θ₂) = (d² - L₁² - L₂²) / (2L₁L₂)
4. θ₂ = ±arccos(cos(θ₂))  // 两个解
5. α = atan2(y, x)
6. β = atan2(L₂sin(θ₂), L₁ + L₂cos(θ₂))
7. θ₁ = α - β
```

**例题 8.2**：
```
机械臂参数：L₁ = 3, L₂ = 2
目标位置：(3, 2)
求θ₁和θ₂（肘部向上解）
```

**解答**：

**步骤1**：计算距离
$$d = \sqrt{3^2 + 2^2} = \sqrt{13} \approx 3.606$$

**步骤2**：检查可达性
$$1 = |3-2| \leq 3.606 \leq 5 = 3+2$$ ✓ 可达

**步骤3**：求 $\theta_2$
$$\cos\theta_2 = \frac{13 - 9 - 4}{2 \times 3 \times 2} = \frac{0}{12} = 0$$
$$\theta_2 = \arccos(0) = 90° = \frac{\pi}{2}$$

（选择正值，肘部向上）

**步骤4**：求 $\theta_1$
$$\alpha = \text{atan2}(2, 3) \approx 33.69° \approx 0.588 \text{ rad}$$

$$\beta = \text{atan2}(2\sin90°, 3 + 2\cos90°) = \text{atan2}(2, 3) \approx 33.69°$$

$$\theta_1 = 33.69° - 33.69° = 0°$$

**答案**：$\theta_1 = 0°$，$\theta_2 = 90°$

**验证**：
$$x = 3\cos(0°) + 2\cos(90°) = 3 + 0 = 3$$ ✓
$$y = 3\sin(0°) + 2\sin(90°) = 0 + 2 = 2$$ ✓

**例题 8.3**：
```
机械臂参数：L₁ = 2, L₂ = 2
目标位置：(2, 2)
求两个解（肘部向上和向下）
```

**解答**：

**步骤1**：
$$d = \sqrt{2^2 + 2^2} = 2\sqrt{2} \approx 2.828$$

**步骤2**：可达性
$$0 \leq 2.828 \leq 4$$ ✓

**步骤3**：
$$\cos\theta_2 = \frac{8 - 4 - 4}{2 \times 2 \times 2} = \frac{0}{8} = 0$$
$$\theta_2 = \pm 90°$$

**解1（肘部向上，$\theta_2 = 90°$）**：
$$\alpha = \text{atan2}(2, 2) = 45°$$
$$\beta = \text{atan2}(2, 2) = 45°$$
$$\theta_1 = 45° - 45° = 0°$$

**解1**：$\theta_1 = 0°$，$\theta_2 = 90°$

**解2（肘部向下，$\theta_2 = -90°$）**：
$$\beta = \text{atan2}(-2, 2) = -45°$$
$$\theta_1 = 45° - (-45°) = 90°$$

**解2**：$\theta_1 = 90°$，$\theta_2 = -90°$

**验证解1**：
$$x = 2\cos(0°) + 2\cos(90°) = 2$$ ✓
$$y = 2\sin(0°) + 2\sin(90°) = 2$$ ✓

**验证解2**：
$$x = 2\cos(90°) + 2\cos(0°) = 2$$ ✓
$$y = 2\sin(90°) + 2\sin(0°) = 2$$ ✓

两个解都正确！

## 8.4 多解问题

### 8.4.1 为什么有多个解？

对于双关节IK，通常有**两个解**：
1. **肘部向上**（$\theta_2 > 0$）
2. **肘部向下**（$\theta_2 < 0$）

有时也称为：
- **右手解**和**左手解**
- **正解**和**负解**

### 8.4.2 选择哪个解？

**策略1：最小运动**
选择与当前姿态最接近的解（最小关节角度变化）。

**策略2：避免奇异点**
避免机械臂完全伸直或完全折叠的姿态。

**策略3：关节限制**
选择满足关节角度限制的解。

**策略4：用户偏好**
根据应用需求（如人形角色通常肘部向下）。

**例题 8.4**：
```
当前姿态：θ₁ = 10°, θ₂ = 80°
新目标有两个解：
解A：θ₁ = 5°, θ₂ = 85°
解B：θ₁ = 70°, θ₂ = -85°
使用最小运动策略，选择哪个？
```

**解答**：

**解A的变化**：
$$|\Delta\theta_1| = |5° - 10°| = 5°$$
$$|\Delta\theta_2| = |85° - 80°| = 5°$$
$$\text{总变化} = 5° + 5° = 10°$$

**解B的变化**：
$$|\Delta\theta_1| = |70° - 10°| = 60°$$
$$|\Delta\theta_2| = |-85° - 80°| = 165°$$
$$\text{总变化} = 60° + 165° = 225°$$

选择**解A**，因为总变化更小。

## 8.5 特殊情况处理

### 8.5.1 完全伸展（奇异点）

当 $d = L_1 + L_2$ 时，机械臂完全伸展：
- $\theta_2 = 0°$
- $\theta_1$ 有唯一解

**例题 8.5**：
```
L₁ = 3, L₂ = 2
目标：(5, 0)
```

**解答**：
$$d = 5 = 3 + 2$$（完全伸展）

$$\cos\theta_2 = \frac{25 - 9 - 4}{12} = \frac{12}{12} = 1$$
$$\theta_2 = 0°$$

$$\theta_1 = \text{atan2}(0, 5) = 0°$$

### 8.5.2 完全折叠

当 $d = |L_1 - L_2|$ 时，机械臂完全折叠：
- $\theta_2 = \pm 180°$
- 存在无穷多解（旋转整个机械臂）

### 8.5.3 数值稳定性

当目标非常接近边界时，可能出现数值问题：
$$\cos\theta_2 = \frac{d^2 - L_1^2 - L_2^2}{2L_1 L_2}$$

可能由于浮点误差导致 $|\cos\theta_2| > 1$。

**解决方案**：钳位
```python
cos_theta2 = (d**2 - L1**2 - L2**2) / (2 * L1 * L2)
cos_theta2 = max(-1, min(1, cos_theta2))  # 钳位到[-1, 1]
```

## 8.6 Python实现

```python
import math

def two_link_ik(x, y, L1, L2, elbow_up=True):
    """
    双关节2D IK求解
    
    参数:
        x, y: 目标位置
        L1, L2: 两段长度
        elbow_up: True表示肘部向上，False表示向下
    
    返回:
        (theta1, theta2) 单位：弧度
        或 None（不可达）
    """
    # 计算距离
    d = math.sqrt(x**2 + y**2)
    
    # 检查可达性
    if d > L1 + L2 or d < abs(L1 - L2):
        return None  # 不可达
    
    # 计算theta2
    cos_theta2 = (d**2 - L1**2 - L2**2) / (2 * L1 * L2)
    cos_theta2 = max(-1, min(1, cos_theta2))  # 钳位
    
    if elbow_up:
        theta2 = math.acos(cos_theta2)
    else:
        theta2 = -math.acos(cos_theta2)
    
    # 计算theta1
    alpha = math.atan2(y, x)
    beta = math.atan2(L2 * math.sin(theta2), 
                      L1 + L2 * math.cos(theta2))
    theta1 = alpha - beta
    
    return (theta1, theta2)

# 测试
L1, L2 = 3, 2
target = (3, 2)

# 肘部向上
result = two_link_ik(target[0], target[1], L1, L2, elbow_up=True)
if result:
    theta1, theta2 = result
    print(f"肘部向上解: θ₁ = {math.degrees(theta1):.2f}°, "
          f"θ₂ = {math.degrees(theta2):.2f}°")

# 肘部向下
result = two_link_ik(target[0], target[1], L1, L2, elbow_up=False)
if result:
    theta1, theta2 = result
    print(f"肘部向下解: θ₁ = {math.degrees(theta1):.2f}°, "
          f"θ₂ = {math.degrees(theta2):.2f}°")
```

## 💡 关键要点总结

1. **双关节IK公式**：
   - $\cos\theta_2 = \frac{d^2 - L_1^2 - L_2^2}{2L_1 L_2}$
   - $\theta_1 = \text{atan2}(y, x) - \text{atan2}(L_2\sin\theta_2, L_1 + L_2\cos\theta_2)$

2. **可达性条件**：$|L_1 - L_2| \leq d \leq L_1 + L_2$

3. **通常有两个解**：肘部向上和向下

4. **选择策略**：最小运动、避免奇异点、关节限制

5. **数值稳定性**：对cos值进行钳位处理

6. **特殊情况**：完全伸展和折叠时需特别处理

# 附录B：常见问题FAQ

## B.1 基础概念

### Q1: IK和FK有什么区别？
**A**: 
- **FK（正向运动学）**：已知关节角度→计算末端位置（简单，唯一解）
- **IK（逆向运动学）**：已知末端位置→计算关节角度（复杂，可能多解或无解）

### Q2: 为什么IK比FK难？
**A**: IK是求解方程，而FK是简单计算：
- FK：直接代入公式即可
- IK：需要求解非线性方程组，可能有0个、1个或多个解

### Q3: IK一定有解吗？
**A**: 不一定。解的情况：
- **无解**：目标不可达（超出工作空间）
- **唯一解**：某些特殊配置
- **多解**：最常见（如双关节有2个解）
- **无穷解**：奇异配置（如完全折叠）

## B.2 双关节IK

### Q4: 双关节IK为什么通常有两个解？
**A**: 想象你的手臂够东西，肘部可以向上或向下弯曲，两种姿势都能让手到达同一位置。这就是"肘部向上"和"肘部向下"解。

### Q5: 如何选择多个解中的哪一个？
**A**: 常用策略：
1. **最小运动**：选择与当前姿态最接近的
2. **避免奇异点**：避免完全伸直或折叠
3. **关节限制**：选择满足角度限制的
4. **应用需求**：如人形角色通常肘部向下

### Q6: 目标不可达怎么办？
**A**: 
1. **检测不可达**：$d > L_1 + L_2$ 或 $d < |L_1 - L_2|$
2. **优雅降级**：朝目标方向完全伸展
3. **告知用户**：返回错误或警告

## B.3 算法选择

### Q7: CCD、FABRIK、雅可比法，应该用哪个？
**A**: 

| 场景 | 推荐算法 |
|------|----------|
| 双关节 | 解析法（最快最准） |
| 多关节简单场景 | FABRIK |
| 需要精确控制 | CCD或雅可比逆 |
| 实时应用 | FABRIK或CCD |
| 有复杂约束 | 雅可比法 |
| 游戏/动画 | FABRIK（效果自然） |

### Q8: 为什么我的IK抖动？
**A**: 常见原因：
1. **在多解间跳跃**：添加解选择逻辑
2. **奇异点附近**：添加阻尼或避免奇异点
3. **步长过大**：减小步长或添加平滑
4. **数值不稳定**：增加误差容差

### Q9: 如何提高IK收敛速度？
**A**: 
1. 好的初始猜测（用前一帧结果）
2. 自适应步长
3. 提前终止（足够接近即可）
4. 选择合适的算法

## B.4 实现问题

### Q10: atan2和atan有什么区别？
**A**: 
- **atan(y/x)**：返回 $(-\pi/2, \pi/2)$，无法区分象限
- **atan2(y, x)**：返回 $(-\pi, \pi]$，正确处理所有象限

**永远使用atan2！**

### Q11: 角度突然从180°跳到-180°，怎么办？
**A**: 这是角度环绕问题。解决方法：
```python
def normalize_angle(angle):
    while angle > math.pi:
        angle -= 2 * math.pi
    while angle < -math.pi:
        angle += 2 * math.pi
    return angle
```

### Q12: 浮点误差导致arccos失败怎么办？
**A**: 钳位到有效范围：
```python
cos_value = max(-1, min(1, cos_value))
theta = math.acos(cos_value)
```

## B.5 3D IK

### Q13: 2D IK和3D IK有什么区别？
**A**: 
- **2D**：简单，通常有解析解
- **3D**：复杂得多，通常需要数值方法
- **3D挑战**：旋转表示（欧拉角、四元数）、万向锁、更多自由度

### Q14: 什么是万向锁？
**A**: 使用欧拉角时，某些姿态会丢失一个自由度。解决：使用四元数或轴角表示。

### Q15: 3D中如何避免关节扭转？
**A**: 
1. 使用关节限制
2. 添加扭转惩罚项
3. 使用轴角或四元数表示
4. 多解中选择扭转最小的

## B.6 性能优化

### Q16: 如何优化IK性能？
**A**: 
1. **缓存计算**：重用FK、雅可比矩阵
2. **早停**：足够接近就停止
3. **限制迭代次数**
4. **LOD**：远处角色用简化IK
5. **多线程**：多个角色并行计算

### Q17: 每帧都要算IK吗？
**A**: 不一定：
- **动态目标**：每帧计算
- **静态目标**：到达后停止
- **可以插值**：降低计算频率，中间帧用插值

### Q18: 如何在移动设备上运行IK？
**A**: 
1. 使用更简单的算法（FABRIK而非雅可比）
2. 降低更新频率
3. 减少关节数量
4. 预计算常见姿态

---

## B.7 约束处理

### Q19: 如何添加关节角度限制？
**A**: 
1. **硬约束**：每次更新后钳位角度
2. **软约束**：在目标函数中添加惩罚项
3. **投影法**：先求解，再投影到可行域

### Q20: 如何处理碰撞？
**A**: 
1. **简单**：检测碰撞后拒绝解
2. **中等**：添加排斥力
3. **复杂**：使用基于约束的优化

### Q21: 多个目标怎么办？
**A**: 
- **优先级IK**：按优先级依次求解
- **加权IK**：加权平均多个目标
- **分层IK**：不同目标控制不同关节子集

## B.8 调试技巧

### Q22: IK不收敛，如何调试？
**A**: 
1. **可视化**：绘制每次迭代
2. **检查FK**：验证FK计算正确
3. **简化问题**：从简单情况开始
4. **打印中间值**：查看误差变化
5. **检查数值问题**：NaN、Inf等

### Q23: 如何验证IK解是否正确？
**A**: 
1. **FK验证**：用求得的角度计算FK，看是否到达目标
2. **误差阈值**：误差小于某个值即可
3. **可视化**：眼睛是最好的验证

### Q24: 如何测试IK实现？
**A**: 
1. **已知解测试**：简单情况（如完全伸展）
2. **边界测试**：工作空间边界
3. **随机测试**：大量随机目标
4. **往返测试**：FK→IK→FK

## B.9 应用相关

### Q25: 游戏中如何平滑IK过渡？
**A**: 
1. **插值**：在解之间线性插值或球面插值
2. **速度限制**：限制关节角速度
3. **阻尼**：添加阻尼避免突变
4. **多帧混合**：多帧平均

### Q26: 角色动画中腿部IK如何实现？
**A**: 
1. **双腿双关节IK**：髋-膝-踝
2. **地面适应**：射线检测地面
3. **步态系统**：结合程序动画
4. **权重混合**：IK与关键帧动画混合

### Q27: 机器人IK和角色IK有何不同？
**A**: 

| 特性 | 机器人 | 角色动画 |
|------|--------|----------|
| 精度要求 | 高（毫米级） | 低（视觉自然） |
| 实时性 | 中等 | 高（60fps） |
| 约束 | 严格 | 灵活 |
| 方法 | 解析/数值 | 快速近似 |

## B.10 进阶话题

### Q28: 什么是冗余自由度？
**A**: 当关节数量多于完成任务所需时，例如：
- 2D平面位置需要2个DOF，3个关节机械臂是冗余的
- 可利用冗余优化其他目标（避障、舒适度等）

### Q29: 如何处理奇异点？
**A**: 
1. **检测**：雅可比矩阵行列式接近0
2. **避免**：添加约束避开奇异配置
3. **阻尼**：阻尼最小二乘法
4. **切换方法**：奇异点附近用其他方法

### Q30: 能否实时修改链结构？
**A**: 可以，但需要：
1. 重新初始化IK求解器
2. 平滑过渡到新配置
3. 保存/恢复状态
